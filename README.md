# WamiaGo Desktop

WamiaGo Desktop is a JavaFX-based desktop application that aims to integrate various transportation services, including taxis, carpooling, relocation transportation, and electric bicycle rentals. This project provides a seamless interface for users to manage and access these services efficiently.

## Features
- **Comprehensive Transport Integration**: Supports multiple transportation modes in a single application.
- **User-Friendly Interface**: Intuitive and easy-to-navigate UI.
- **Real-Time Synchronization**: Keeps data updated across devices.

## Usage
1. Open the WamiaGo Desktop application.
2. Log in with your WamiaGo credentials.
3. Access various transportation services and customize settings as needed.

## Development Setup
### Prerequisites
- Java Development Kit (JDK 17 or later)
- JavaFX SDK
- Git
- Maven (for dependency management)

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/AtfastrSlushyMaker/WamiaGo-Desktop.git
   cd WamiaGo-Desktop
   ```
2. Install dependencies:
   ```bash
   mvn clean install
   ```
   
3. Run the application in development mode:
   ```bash
   mvn javafx:run
   ```
